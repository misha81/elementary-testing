# Elementary Math Testing Platform (Archive)

An interactive, frontend-only educational web application designed to help primary school children practice basic mathematics. 

*Note: This is an early-learning archival project created in 2023 to practice Vanilla JavaScript and basic DOM manipulation.*

## 🚀 Features
- **Grade Selection:** Users can choose their current school level (Grades 1 through 4) using a kid-friendly visual menu[cite: 19].
- **Two Learning Modes:** 
  - *Equations (Приклади):* Dynamically generates random arithmetic problems[cite: 20, 23].
  - *Word Problems (Задачі):* Pulls logic and math text problems from a pre-defined JS array[cite: 20, 25, 26].
- **Customizable Tests:** Includes a slider interface allowing users to select the desired number of questions before starting the test[cite: 22].
- **Automated Grading:** Calculates the final score automatically upon completion, displaying the result as a fraction (e.g., 3/3), a percentage, and its equivalent in the 12-point grading system[cite: 24].

## 🛠 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
